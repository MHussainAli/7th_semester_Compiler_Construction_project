# Algorithms Implemented

| Area | Implementation |
|---|---|
| Lexical analysis | Regular-expression based scanner |
| Automata | Thompson NFA construction, subset construction NFA→DFA |
| DFA | Partition-refinement minimization |
| Grammar | FIRST/FOLLOW |
| Parsing | LL(1) table generation, recursive descent |
| Intermediate code | Three-address code, quadruples |
| Optimization | Constant folding, algebraic simplification |
| Target generation | Simple register-style pseudo assembly |

The project is intentionally an educational subset, not a replacement for industrial compiler tools.
