# Viva Guide

**Compiler:** translates source code into another target representation.

**Lexer:** converts characters into tokens.

**Parser:** checks token sequences against grammar rules.

**Semantic analyzer:** checks meaning-related constraints such as declarations and types.

**FIRST:** terminals that may begin strings derived from a grammar symbol.

**FOLLOW:** terminals that may appear immediately after a non-terminal.

**TAC:** an intermediate representation using simple three-address instructions.

**Optimization:** transforms code to remove unnecessary work while preserving behavior.

**Target code:** a lower-level representation produced from the intermediate form.
