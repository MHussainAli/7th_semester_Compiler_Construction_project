# Compiler Construction Studio — Project Report

## Purpose
An educational mini-compiler demonstrating the major stages in the supplied Compiler Construction outline.

## Stages
1. Lexical Analysis
2. Grammar / Syntax Analysis
3. Semantic Analysis
4. Intermediate Code Generation
5. Code Optimization
6. Target Code Generation

## Demonstration
Input is converted to tokens, checked against symbol information, represented as three-address instructions, optimized, and translated to simple pseudo-assembly.

## Academic Extensions
The repository is intentionally modular so NFA/DFA, LL(1), LR-family parsers, richer type checking and visualization can be added as separate experiments.
